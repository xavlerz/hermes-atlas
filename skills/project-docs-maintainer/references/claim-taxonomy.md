# Claim taxonomy

- **Observed:** directly confirmed in current source, tests, command output, or an authoritative artifact; cite the evidence and date/commit when useful.
- **Inferred:** reasoned from evidence but not directly established; label the reasoning and uncertainty, and state what would confirm it.
- **Proposed:** intended future work or recommendation; do not imply approval, schedule, or implementation.

For architecture, describe files and actual flows, not aspirational design. For state, record the baseline and exact checks. A passing static check does not establish runtime or production behavior.
